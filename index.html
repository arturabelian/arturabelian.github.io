NAME

artur - reverse engineers software, analyzes binaries, studies vulnerabilities

SYNOPSIS

artur [--static] [--dynamic] [--deep] binary ... [OPTIONS]

DESCRIPTION

Software engineer and cybersecurity enthusiast from Belarus. Reverse engineering, binary analysis and low-level systems research.

Investigates software from the outside in: examines executable formats, follows control flow, studies memory and runtime behavior, and reconstructs the logic hidden behind compiled code.

A binary is a source of evidence. Disassembly reveals instructions; debugging exposes runtime state; traces explain interactions with the OS. The goal is to understand what the program actually does — not what its interface or documentation claims.

Interested in the boundary between source code, machine code and execution: calling conventions, memory layout, system calls and undocumented behavior. Values small tools, clear reasoning and reproducible analysis.

OPTIONS

--static
Inspects executable structure, strings, symbols, imports and disassembly.
--dynamic
Follows execution with a debugger; examines registers, memory and system calls.
--deep
Reconstructs program logic, investigates vulnerabilities and documents findings.
--research
Explores binary behavior, software internals and security assumptions.
--projects
Opens public code and current work on GitHub.
